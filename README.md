# סטודיו רוני — דף נחיתה

מומר מפיגמה ל-React + Tailwind, מוכן להעלאה ל-Lovable.

## קבצים

| קובץ | מה זה |
|---|---|
| `preview/roni-portfolio.html` | תצוגה מקדימה — פותחים בדפדפן, לא נדחף ל-Lovable |
| `src/components/RoniPortfolio.tsx` | הקומפוננטה האמיתית — זה מה שנדחף |
| `src/index.css` | טוקנים של עיצוב (HSL CSS variables) + הזוהר והזכוכית |
| `tailwind.config.ts` | מיפוי הטוקנים ל-Tailwind |
| `public/assets/` | התמונות |
| `ASSETS.md` | רשימת התמונות לייצוא מפיגמה |

## איך זה בנוי

העיצוב בפיגמה הוא קנבס של **1728 × 8958** עם מיקום אבסולוטי לכל אלמנט. כדי לשמור על
דיוק של פיקסל בלי לעוות כלום, כל המידות נשמרות ב־*פיקסלים של העיצוב* ומומרות ליחידה
יחסית לקונטיינר:

```css
--u: calc(100cqw / 1728);   /* פיקסל אחד של העיצוב */
```

כך שהקנבס כולו מתכווץ ומתרחב פרופורציונלית לרוחב המסך — בכל רוחב זה נראה בדיוק כמו
בפיגמה, ואף תמונה לא נמתחת. מתחת ל-`lg` (1024px) יש פריסה נפרדת לנייד עם אותו תוכן,
בזרימה רגילה במקום מיקום אבסולוטי.

## טיפוגרפיה

`IBM Plex Sans Hebrew` — משקלים 400 / 500 / 600 / 700. להוסיף ל-`index.html`:

```html
<link href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+Hebrew:wght@400;500;600;700&display=swap" rel="stylesheet">
```

## צבעים (מפיגמה)

| טוקן | Figma | HSL |
|---|---|---|
| `--brand` | `#e0783c` | `22 73% 56%` |
| `--brand-light` | `#fa9154` | `22 94% 65%` |
| `--heading-from` | `#8da8cb` | `214 37% 67%` |

הכתום בכפתורים: `linear-gradient(to left, #e0783c, #fa9154)`.
הכותרות: `linear-gradient(to right, #8da8cb, #fff)` עם `background-clip: text`.
הזכוכית: `linear-gradient(237.5deg, rgba(255,255,255,0) 12.5%, rgba(255,255,255,.2) 87.5%)`
עם `backdrop-blur: 42.3px` ורדיוס 20.

## מה עוד לא מחובר

- **הטופס** לא שולח לשום מקום — צריך לחבר ל-Supabase / Formspree / webhook.
- **תפריט ההמבורגר** הוא כרגע כפתור בלי תפריט.
- **הכפתורים** (`לתיק עבודות`, `בואו נדבר`, `למעבר לפרוייקט`) בלי `href`.
- **תמונות הפרויקטים** — מסכי הלפטופ לבנים, ראה `ASSETS.md`.

## דחיפה ל-Lovable

עולה קרדיטים, ולכן לא נעשה. כשרוצים — דוחפים את `RoniPortfolio.tsx` + `public/assets/`
ומבקשים מהסוכן *לחבר* (לא לבנות מחדש): לחווט ל-route, להשתמש בטוקנים מ-`index.css`,
`@/` alias, `lucide-react` לאייקונים, ולמקם את התמונות ב-`public/`.
